# Q: Почему после сохранения двухразового питания локальный интерфейс продолжал показывать три приема?

## Answer

На порту 4173 оставался процесс tests/dev-server.mjs, запущенный 26 июля до добавления mealCountChanges. Новые статические assets/app.mjs загружались с диска, но старый Node-процесс использовал загруженную в память прежнюю normalizeFeedingSettings и возвращал профиль без mealCountChanges. После перезапуска сервера сохранение даты 2026-07-28 с mealsPerDay=2 прошло, API вернул эту запись, а повторный рестарт сохранил режим и интерфейс показал 2 приема.
