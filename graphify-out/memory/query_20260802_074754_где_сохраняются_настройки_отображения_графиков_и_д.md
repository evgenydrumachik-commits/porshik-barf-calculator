# Q: Где сохраняются настройки отображения графиков и диапазоны?

## Answer

Диапазоны графиков и ось нормы хранятся в localStorage браузера: porschik_chart_date_ranges и porschik_norm_chart_axis. Переключатели видимости серий пока хранятся только в runtime state и сбрасываются после перезагрузки. Сервер хранит записи дневника и общие настройки кормления, но текущий код не отправляет туда настройки отображения.
